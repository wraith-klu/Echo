⚠️ Critical Voltage Warning: The INMP441 MEMS microphone operates strictly at 3.3V. Connecting its VDD pin to 5V will permanently damage the sensor.

🛠️ 2. Arduino IDE One-Time Setup

  1. Download and launch Arduino IDE.
  2. Open File ➔ Preferences.
  3. In the Additional Boards Manager URLs field, paste this exact URL: 
    https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
  4. Open Tools ➔ Board ➔ Boards Manager..., search for esp32 by Espressif Systems, and click Install.
  5. Open Tools ➔ Manage Libraries... (Ctrl + Shift + I), search for WebSockets by Markus Sattler, and click Install.

⚙️ 3. Configuring the Firmware (echo_esp32.ino)

Open echo_esp32.ino in Arduino IDE and update lines 8–18 with your local network settings:

// 1. Enter your Wi-Fi credentials
const char* WIFI_SSID     = "YOUR_WIFI_NAME";
const char* WIFI_PASSWORD = "YOUR_WIFI_PASSWORD";

// 2. Set your computer's local IPv4 running the FastAPI backend
const char* BACKEND_HOST  = "192.168.1.15"; // Run 'ipconfig' in terminal
const int   BACKEND_PORT  = 8000;

// 3. Set desired target language ('hi', 'es', 'fr', 'de', etc.)
const char* TARGET_LANG   = "hi";
const char* DEVICE_ID     = "ESP32_001";
💡 Finding your PC's IP address: Open PowerShell or CMD on your PC and run ipconfig. Look for the IPv4 Address under your connected Wi-Fi or Ethernet adapter (e.g., 192.168.1.XX).

⚡ 4. Board Settings & Flashing

Under the Tools menu in Arduino IDE, apply these settings:

  • Board: ESP32S3 Dev Module
  • USB CDC On Boot: Enabled
  • Upload Speed: 921600
  • Flash Size: 4MB (or 8MB/16MB depending on module)
  • Port: Select the COM port connected to the ESP32-S3 (e.g. COM3, COM5)

Flashing Steps:

  1. Press and hold the BOOT button on your ESP32-S3.
  2. Click the Upload button (or press Ctrl + U).
  3. Once the console outputs Writing at 0x00010000..., release the BOOT button.
  4. Wait for the confirmation message: Hard resetting via RTS pin... (Done!).

🚀 5. Testing & Live Translation Verification

  1. Open the Serial Monitor in Arduino IDE (Ctrl + Shift + M) and set the speed to 115200 baud.
  2. Press the EN (Reset) button on the ESP32.
  3. Verify the initial handshake: 
    Connecting to Wi-Fi: MyHomeWiFi
....
Wi-Fi Connected! IP: 192.168.1.45
[WS] Connected to Echo Backend!
  4. Speak into the INMP441 Microphone:

    The ESP32 continuously streams 16-bit 16kHz PCM audio chunks to the server. Once you pause, the backend VAD detects speech boundary and processes ASR ➔ Translation ➔ TTS.

    [Translation JSON]: {"transcription":"Hello, how are you?","translation":"नमस्ते, आप कैसे हैं?","latencies":{"total_sec":3.2}}
[Audio In]: Playing 34816 bytes of translated speech...
  5. The translated audio will play directly through the connected MAX98357A speaker!
